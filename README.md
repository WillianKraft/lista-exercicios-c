# Lista de Exercícios em C

Repositório com 10 exercícios de lógica de programação, resolvidos a partir de uma lista de pseudocódigo com estruturas sequenciais e condicionais, implementados em linguagem C. Desenvolvidos durante meus estudos de Engenharia de Software na UniSenai.

## Objetivo

Praticar leitura de dados, cálculos e estruturas de decisão (`if` / `else if` / `else`) através de exercícios organizados por nível de dificuldade.

## Tópicos abordados

- Entrada e saída de dados (`scanf`, `printf`)
- Variáveis e tipos primitivos (`int`, `float`)
- Estruturas condicionais simples, compostas e encadeadas
- Operadores relacionais e lógicos (`&&`, `>=`, `<=`, `%`)
- Cálculos aplicados a problemas reais (descontos, tarifas, médias, reajustes)

## Exercícios

### Nível básico
| Arquivo | Descrição |
|---|---|
| `exercicio_1.c` | Lê dois números inteiros e calcula a soma |
| `exercicio_2.c` | Lê duas notas, calcula a média e informa Aprovado (≥7) ou Reprovado |
| `exercicio_3.c` | Verifica se um número é par ou ímpar usando o operador `%` |

### Nível médio
| Arquivo | Descrição |
|---|---|
| `exercicio_4.c` | Calcula desconto em uma compra (12% acima de R$ 300, 5% abaixo) e mostra o valor final |
| `exercicio_5.c` | Calcula reajuste salarial (10% abaixo de R$ 2.500, 6% acima) e mostra o novo salário |
| `exercicio_6.c` | Calcula consumo médio (km/l) e classifica como Eficiente (≥12 km/l) ou Baixa Eficiência |
| `exercicio_7.c` | Classifica a idade em Criança, Adolescente, Adulto ou Idoso |
| `exercicio_8.c` | Lê três números e identifica qual é o maior |

### Nível avançado
| Arquivo | Descrição |
|---|---|
| `exercicio_9.c` | Calcula o valor da conta de luz com tarifas progressivas por faixa de consumo (kWh) |
| `exercicio_10.c` | Lê 3 notas e a frequência, calcula a média e informa Aprovado, Recuperação ou Reprovado |

## Como executar

Compile qualquer exercício com o GCC:

```bash
gcc exercicio_X.c -o exercicio_X
./exercicio_X
```

## Tecnologias

- Linguagem C
- Compilador GCC
